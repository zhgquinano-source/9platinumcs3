# SG4 - Understanding Classes and Objects
## Class Name
Songs

## Class Description
A song is a short piece of music with words that people sing

## Properties
| Property | Data Type | Description |
|----------|----------|------------|
| Song name | string  | The name of the song |
| Genre    | string   | Genre of the song |
| Duration | int      | How long the song lasts |
| Album    | string   | The album where the song belongs |
| Artist   | string   | The person/people who created the song |

## Methods
| Method | Description |
| -------| ----------- |
| Play song | Plays the song |
| Stop song | Stops the song |

## Design Explanation
### Why did you choose this class?
Because I love listening to music(Arctic Monkeys and IV of Spades)

### Which property is the most important? Why?
Song name is the most important property because it identifies the song and helps people know which song they are listening to.

### Which method is the most useful? Why?
Play is the most useful method, because it allows the user to listen to the song, which is the main purpose of a song object.
